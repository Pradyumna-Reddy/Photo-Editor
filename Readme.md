# Photo Editor Engine (Python)

A Photo editor app backend build in python, used to manipulate images similar to filter/edit image applications in mobile.

## Features (in progress)

Load, edit, and save static images

Apply filters such as crop, contrast, brightness

Extensible filter architecture (goal).

Initially designed for CLI and then UI integration.


## Tech Stack

- Python 3
- Pillow
- Numpy
- Pytest

## Project goals

A usable image editor (eventual goal) which can pave path to understanding of image manipulation
and large data handling.
